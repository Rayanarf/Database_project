# Database Systems Project

This repository contains the files for our Database Systems project, **Fast Fix Garage**.

The project uses MySQL, PHP, HTML, and CSS to build a database and a simple web application for managing a car repair garage.

The repository will include the SQL files for the database, along with the PHP, HTML, and CSS files for the final project.
